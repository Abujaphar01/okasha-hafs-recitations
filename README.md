# Sheikh Okasha Kameny — Hafs 'An-Asim Recitations (Web App & PWA)

> **قُلْ إِنَّ هُدَى اللَّهِ هُوَ الْهُدَىٰ**  
> *A sanctuary of forensically audited Quran recitations by Sheikh Okasha Hassan Kameny, strictly adhering to the **Ḥafṣ ʿan ʿĀṣim (حفص عن عاصم)** narration.*

---

## 🌟 Key Features

1. **100% Pure Ḥafṣ ʿan ʿĀṣim Certification**
   - Each verse was forensically audited against classical Tajwīd and *Matn ash-Shāṭibiyyah* criteria.
   - Any recitation containing non-Ḥafṣ variants (such as Warsh, Khalaf, or phonetic slips like *juthiyyā* with ḍammah) has been strictly disqualified.

2. **Progressive Web App (PWA) & Offline Ready**
   - Installable on desktop (Google Chrome, Microsoft Edge) and mobile (Android, iOS Safari).
   - Service Worker caching allows instant loading and complete offline listening.
   - Built-in "Save Offline" feature allows downloading all 9 recitations into browser cache.

3. **Deluxe Audio Player UX**
   - **3-State Loop Controller**: Cycle between `🔁 Repeat All`, `🔂 Repeat One`, and `➡️ Sequence (Off)`.
   - **Live Soundwave Equalizer**: Dynamic animated bars indicating the currently active recitation.
   - **Playback Speed Controller**: 1.0x, 1.25x, 1.5x, 1.75x, 2.0x, 0.75x.
   - **Quick Scrubbing**: -10s rewind and +10s fast forward buttons.
   - **Keyboard Shortcuts**: Space (Play/Pause), Left/Right Arrows (Seek), 'L' (Loop mode), 'S' (Speed).
   - **Media Session API**: Integrates with device lock screens and notification controls.

## 🚀 How to Run Locally

Double-click `launch_app.bat` in this folder, or run:
```bash
python -m http.server 8000
```
Then navigate to:
```
http://localhost:8000
```

---

## 📱 How to Install on Mobile & Desktop

- **Chrome / Edge (Desktop & Android)**: Click the **"Install Web App"** badge in the header, or click the install icon in the URL address bar.
- **Safari (iPhone / iPad)**: Tap the **Share** button (box with upward arrow) -> Tap **"Add to Home Screen"**.
